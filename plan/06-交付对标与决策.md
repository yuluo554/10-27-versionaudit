## 三、决策记录

| # | 日期 | 决策 | 理由 |
|---|---|---|---|
| D1 | 2026-10-27 | 首期仅 npm，不写跨生态解析器 | `data/README.md` §2 同形异义（裸 `1.2.3` npm 精确 / Cargo caret）；复用解析器必然产出错误结论 |

| D3 | 2026-10-27 | `semver` 钉死 `7.8.5`，不写 `^` | 语义结论必须绑定实现版本（`data/README.md` §1.1 有 7.7.4/7.8.5 交叉记录） |
| D4 | 2026-10-27 | 无构建步骤（纯 ESM JS + JSDoc），不用 TS | 保证"仓库即产物"，确定性双跑不被构建产物遮蔽 |
| D5 | 2026-10-27 | 灰区全部配置化，默认档在报告里回显 | `plan/01` §3.6；默认表是**策略**不是事实，不回显就无法审计 |

| D7 | 2026-10-27 | `resolved` 只作字符串留档，不解析主机 | 零联网红线（`data/README.md` §5） |
| D8 | 2026-10-27 | 不做 monorepo/workspace（roadmap） | `plan/01` §7 边界；首期单包 |
| D9 | 2026-10-27 | 发布附件 = `git archive` 源码包 + `SHA256SUMS`，不产 wheel | 无构建步骤的项目，源码包即产物；`SHA256SUMS` 可本地复算 |
| D10 | 2026-10-27 | 向量不进 npm 包（`files` 白名单不含 `fixtures/`） | 包体最小；向量属仓库资产，CI 才跑 |
